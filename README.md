# Aurum Corporate Gifts Website

This is a static multi-page website for a premium corporate gifting company. It has no paid plugin, database, or backend requirement.

## Pages

- `index.html` - homepage
- `collections.html` - gift collection categories
- `services.html` - process and service details
- `about.html` - brand positioning
- `contact.html` - quote request page using a free mailto form

## Customize

- Change the company name from `Aurum Corporate Gifts` to your real brand name in the HTML files.
- Replace `hello@aurumgifts.com` and `+91 00000 00000` in `contact.html` and `assets/site.js`.
- Replace `assets/luxury-gifting-hero.png` with your own product photo if you have one.
- Update collection names, budget language, and delivery areas to match your business.

## Low-cost publishing

- Free: GitHub Pages
- Free starter plans: Netlify or Vercel
- Lowest ongoing cost: use your own domain only, then host this static site on a free plan

Because it is static HTML, CSS, and JavaScript, it can be uploaded without a website builder subscription.
